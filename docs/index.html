02

Danh mục theo dõi

Gõ các mã cần quét, cách nhau bởi dấu phẩy hoặc xuống dòng (VD HPG, VNM, SSI). Bấm Chuẩn hoá & sao chép rồi dán vào GitHub — job đọc danh mục từ đó.
Chưa có mã nào.
Dán vào: GitHub → repo → Settings → Secrets and variables → Actions → tab Variables → WATCHLIST (lần đầu bấm New repository variable, đặt tên đúng WATCHLIST) → dán → Save. Sau đó vào Actions → daily → Run workflow để quét ngay, hoặc chờ 15:35. Mã mới có hiệu lực từ lần job chạy kế tiếp.
03

Xu hướng · Supertrend

Supertrend (10 phiên, 3 × ATR kiểu Wilder — giống TradingView) kết hợp EMA10. Chỉ chiều mua; tín hiệu đỏ là lời nhắc thoát hàng. Mỗi tín hiệu là một thông báo riêng, không gộp vào bản tổng hợp — hiếm (~1/phiên cả danh mục) và kèm mức dừng lỗ.
Đo 11/2019 → 09/2026, 39 mã, khớp mở phiên sau, T+2, có phí: +6,71 %/lệnh, thắng 47 %, profit factor 2,65, giữ trung vị 34 phiên; mốc mua đại rồi giữ 34 phiên +3,93 %. Cả kỳ +212 % so với mua-và-giữ +294 %, nhưng sụt giảm sâu nhất −42 % so với −63 %. Cả 18 tổ hợp tham số lân cận đều dương. Tái lập: scripts/replay_trend.py.
